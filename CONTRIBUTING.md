# Contributing

Issues and pull requests are welcome. Be respectful and focus feedback on the work.

Before a large change, open an issue explaining the user problem and proposed approach. For bugs, include reproduction steps, expected behavior, browser version, and sanitized screenshots. Do not attach API keys, personal interview answers, or recordings.

Fork the repository, create a focused branch, install with `npm ci`, and run the tests and production build described in the README. Include relevant tests for behavior changes and check keyboard access, narrow screens, and the `/interviewcrack/` deployment path. Describe what changed and how you verified it in your pull request.

Contributions must be yours to share and are submitted under this repository's MIT license. Keep third-party license notices. Never introduce shared API credentials or collect user recordings without an explicit, documented user choice.
