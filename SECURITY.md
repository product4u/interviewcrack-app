# Security and privacy

Never include credentials or personal practice data in public issues. Report vulnerabilities privately using GitHub's **Security → Report a vulnerability** when available. If private reporting is unavailable, request a private contact channel without publishing exploit details.

Only the current `main` branch is maintained, on a best-effort basis; response times are not guaranteed. If a key is exposed, revoke it with its provider immediately. Deleting a file or commit does not make the key safe again.

This browser-only app uses user-provided Gemini keys. Session storage is the default, with optional persistent local storage. Neither protects against malicious browser extensions or injected scripts. Use a dedicated key, provider restrictions/quotas, and a trusted device; self-host if preferred. Other apps on the same GitHub Pages origin can share browser storage, so only host trusted projects on that account's Pages origin.

The application uses local browser storage for saved practice. AI requests transmit submitted content to Google, and browser speech recognition may use the browser vendor's service. Do not submit confidential material. Review provider terms before using AI features.
